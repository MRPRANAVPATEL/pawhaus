# Pawhaus — Premium Pet Ecommerce Frontend

A single-page, frontend-only pet essentials storefront built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. No build step, package manager, backend, or framework is required.

## Included interactions
- Responsive mobile navigation
- Scroll-triggered reveal animations
- Animated ticker and hero image entrance
- Product category filters
- Frontend-only add-to-bag counter
- Search overlay
- Local newsletter form confirmation

## Notes
- This is a visual prototype. Cart, search, and newsletter interactions do not connect to a backend or persist data.
- Product and lifestyle images load from Unsplash and Google Fonts load from Google Fonts, so an internet connection is required for those assets.
- Motion respects `prefers-reduced-motion`.
- CSS includes responsive rules at 1200px, 900px, 650px, 420px, and 350px.
