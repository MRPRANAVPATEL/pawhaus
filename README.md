# Pawhaus | Premium Website Template

**Thoughtfully built by Pranav Patel.**

Premium responsive pet essentials eCommerce website template built with HTML, CSS and JavaScript.

> **Portfolio / practice project:** Created for personal practice, design exploration and showcasing frontend development. This repository is a website template, not an operating store or publishing platform. Use and adapt at your discretion, and review asset rights and third-party dependencies before production use.

## About the template

Pawhaus is a polished, single-page frontend concept designed for pet accessories brands, boutique dog shops, and pet lifestyle storefronts. It focuses on visual storytelling, considered typography and responsive interactions without requiring a frontend framework or build process.

## Features

- Editorial-style storefront with an immersive dog-focused hero
- Pet product collections and category filters
- Interactive frontend add-to-bag counter and search overlay
- Responsive mobile navigation and scroll animations
- Newsletter confirmation demo

## Built with

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Clone or download this repository.
2. Open `index.html` in your browser, or run it using VS Code Live Server.
3. No install, build process or package manager is needed.

- **GitHub Pages:** https://mrpranavpatel.github.io/pawhaus/ (available after Pages is enabled and published)

## Deployment

This repository includes a root-level `index.html` and can be hosted as a static website on GitHub Pages or Vercel.

For GitHub Pages, open **Settings → Pages**, select **Deploy from a branch**, choose **main** and **/(root)**, and save. Once GitHub finishes publishing, the GitHub Pages URL above should work.

## Important notes

Cart, search and newsletter features are frontend demonstrations only. No checkout, payments, database, or live newsletter subscription is connected.

External media, imagery and fonts may require an internet connection. Review licensing and replace demonstration content before commercial use.
